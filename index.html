About AI

AI, without the mystery.

the algorithm doesn't drink coffee. we do.

How AI is used here

After your mood, budget, taste, and dietary answers pass through deterministic filtering, the eligible items — never the whole menu — are sent to an AI model to rank by preference and write a one-line explanation. The model never sees full menu data, only what's needed to reason.

What code controls, always

Price, ingredients, dietary tags, allergens, and availability are attached from our structured menu data after the AI responds — never generated, never edited by the model. The AI can only choose among items that already passed the hard filters.

Where AI is not trusted for facts

  • Prices
  • Ingredients
  • Dietary classifications
  • Allergens
  • Rewards
  • Core menu data

Validated before you see it

Every AI response is checked: is the item ID real, was it in the eligible set, does it still fit the budget and diet you picked? If any check fails, the result is replaced by our deterministic house rules and labeled "Rule-based fallback" — never shown as if it came from the model.

What the model receives

Only your selected mood and taste preferences plus the eligible candidate list (id, name, category, price, temperature, caffeine, taste and mood tags). No name, no device or account identifiers, no Cloud Coins or Passport history, no free-form text from you.

What we don't ask for

  • Names
  • Phone numbers
  • Emails
  • IDs
  • Payment information
  • Location

An honest limitation

This page calls the AI model directly from your browser using this platform's built-in, keyless request path — no API key is ever embedded in this page's code. That mechanism only works while this page is running inside Claude's own preview environment. If this file is hosted elsewhere as a plain website, that request will fail automatically and safely: Find My Cup falls back to the deterministic house rules every time, clearly labeled "Rule-based fallback." A true always-on deployment would need a small real server holding its own key — not built or deployed here.

Who gets the final say?

You do. Always.
